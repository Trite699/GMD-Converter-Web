# MCA ↔ WAV Converter (Web)

A lightweight **browser-based converter** for Capcom `.gmd` (Game Message Adapter) script files and standard `.txt` files.

Supports:
- GMD → TXT (decode)
- TXT → GMD (encode)
- GMD → USER.2 (encode]
- Multiple GMD versions (V1/V2)

No installation required — runs entirely in your browser.

---

##  Features

-  Convert **GMD → TXT**
-  Convert **TXT → GMD**
-  Convert **GMD → USER.2**
-  Version Auto detection
-  Supports Capcom GMD formats:
  - V1 (AA5)
  - V2 (AA6,TGAAC,DGS1/2)
- In-browser editing

##  Issues
- Special GMDs might not work properly 
- Large files may use more memory
